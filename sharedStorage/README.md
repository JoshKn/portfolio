# Shared-Storage-Automatisierung

Dieser Ordner enthält ausgewählte Skripte und Konfigurationsbeispiele aus der Arbeit mit einer Shared-Storage-Infrastruktur in der Postproduktionsumgebung.

## Inhalte

- Installation bzw. Aktualisierung von Shared-Storage-Software
- Verwaltung von Konfigurationen
- Automatisierung wiederkehrender Administrationsaufgaben

## Hinweis

Die ursprünglichen Skripte wurden für dieses öffentliche Repository angepasst. Servernamen, Pfade, Konfigurationen und andere Informationen über die produktive Infrastruktur wurden entfernt oder anonymisiert.
