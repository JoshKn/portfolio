# Verarbeitung einer Casting-Mediendatenbank

Dieses Projekt umfasst mehrere Python-Skripte zur Vorbereitung und automatisierten Verarbeitung einer großen Anzahl von Mediendateien.

## Hintergrund

Die Medien einer bestehenden Datenbank sollten standardisiert konvertiert und nach Dateityp sortiert werden. Vor der eigentlichen Konvertierung mussten die vorhandenen Dateien analysiert und in eine einheitliche Dateibenennung überführt werden.

Die eigentliche Medienkonvertierung erfolgte anschließend automatisiert mit FFAStrans.

## Aufgaben der Skripte

Die enthaltenen Python-Skripte übernehmen verschiedene Aufgaben, unter anderem:

- Erfassen vorhandener Dateien
- Analysieren von Verzeichnisstrukturen
- Erfassen von IDs und Metadaten aus Dateistrukturen
- Filtern von Dateien anhand verschiedener Kriterien
- Vorbereitung der Dateien für die weitere automatisierte Verarbeitung

## Hinweis

Die hier veröffentlichten Skripte wurden für das Portfolio gekürzt und anonymisiert. Unternehmensspezifische Daten, Pfade und Bezeichnungen wurden entfernt oder ersetzt.
