# Portfolio – Medientechnologie & Softwareentwicklung

Dieses Repository enthält eine Auswahl an Projekten, Skripten und Übungen aus meinem Studium der Medientechnologie an der TH Köln sowie Beispiele aus meiner beruflichen Tätigkeit im technischen Umfeld der Medienproduktion.

## Berufliche Projekte

Ein Teil der enthaltenen Skripte und Tools entstand im Rahmen meiner beruflichen Tätigkeit. Dazu gehören unter anderem Werkzeuge zur Automatisierung von Avid-Workflows, zur Verarbeitung größerer Medienbestände sowie Skripte zur Administration technischer Systeme.

### Hinweis zu betrieblichen Inhalten

Alle hier veröffentlichten Beispiele aus meiner beruflichen Tätigkeit wurden vor der Veröffentlichung gekürzt, anonymisiert und teilweise angepasst.

Unternehmensspezifische Namen, Server- und Netzwerkpfade, Zugangsdaten, interne Konfigurationen sowie andere Informationen über die Infrastruktur des Unternehmens wurden entfernt oder durch neutrale Bezeichnungen ersetzt.

## Uni-Projekte

Die Projekte stammen aus meinem Studium der Medientechnologie an der TH Köln und umfassen unter anderem:

- Digitale Bildverarbeitung
- Digitale Signalverarbeitung
- Computer Vision
- Machine Learning
- Python

## Ausgewählte Projekte

### Avid Bin Creator
Python-Tool zur automatisierten Erstellung von Avid-Bins auf Basis vorhandener Verzeichnisstrukturen.

→ [`avid_bin_creator/`](avid_bin_creator/)

### Avid Project Creator
Python-Anwendung zur automatisierten Erstellung von Avid-Projekten aus bestehenden Verzeichnisstrukturen.

→ [`avid_project_creator/`](avid_project_creator/)

### Casting Database Processing
Python-Skripte zur Aufbereitung und automatisierten Verarbeitung eines größeren Medienbestands in Verbindung mit FFAStrans.

→ [`casting_db/`](casting_db/)

### Bildverarbeitung
Übungen und Projekte aus den Modulen Bildverarbeitung 1 und 2, darunter klassische Bildverarbeitung sowie erste Anwendungen von Machine Learning und PyTorch.

→ [`thkoeln_bildverarbeitung_1/`](thkoeln_bildverarbeitung_1/)  
→ [`thkoeln_bildverarbeitung_2/`](thkoeln_bildverarbeitung_2/)

### Signaltheorie
Übungen und Praktika zur digitalen Signalverarbeitung.

→ [`thkoeln_signaltheorie/`](thkoeln_signaltheorie/)

### Systemadministration
Ausgewählte Skripte zur Automatisierung wiederkehrender Administrationsaufgaben unter Windows und im Bereich Shared Storage.

→ [`windows_admin/`](windows_admin/)  
→ [`sharedStorage/`](sharedStorage/)
