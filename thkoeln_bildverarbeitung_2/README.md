# Bildverarbeitung 2

Dieser Ordner enthält Übungen und Projekte aus dem Modul Bildverarbeitung 2 aus meinem Studium.

Der Schwerpunkt liegt auf der Anwendung von Machine Learning und neuronalen Netzen auf Aufgaben der Bildklassifikation.

## Inhalte

Die enthaltenen Jupyter Notebooks behandeln unter anderem:

- Grundlagen von PyTorch
- Aktivierungsfunktionen
- Training einfacher neuronaler Netze
- Klassifikation des MNIST-Datensatzes
- Analyse von Gradienten
- Training und Evaluation von Modellen zur Verkehrszeichenerkennung mit dem GTSRB-Datensatz
- Analyse von Loss und Accuracy während des Trainings
