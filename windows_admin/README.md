# Windows Administration & Automation

Dieser Ordner enthält eine Auswahl kleinerer Skripte zur Automatisierung von Administrationsaufgaben auf Windows-Systemen.

## Beispiele

Die enthaltenen Skripte beschäftigen sich unter anderem mit:

- Installation und Aktualisierung von Software
- Überprüfung installierter Programmversionen
- Verwaltung von Benutzer- und Netzwerkeinstellungen
- Dateioperationen auf entfernten Systemen
- Konfiguration von Windows-Zeitservern
- Cache-Bereinigung

## Hinweis

Die Skripte wurden vor der Veröffentlichung anonymisiert und teilweise gekürzt. Interne Rechnernamen, Netzwerkpfade, Benutzerinformationen und weitere unternehmensspezifische Konfigurationen wurden entfernt oder ersetzt.
