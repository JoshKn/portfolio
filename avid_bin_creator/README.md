# Avid Bin Creator

Der Avid Bin Creator ist ein Python-Tool zur automatisierten Erstellung von Avid-Bins auf Basis bestehender Windows-Verzeichnisstrukturen.

## Hintergrund

Bei der Vorbereitung von Avid-Projekten müssen vorhandene Verzeichnisstrukturen teilweise manuell als entsprechende Bin-Strukturen in Avid Media Composer angelegt werden.

Das Tool entstand mit dem Ziel, diesen wiederkehrenden Arbeitsschritt zu automatisieren und die Vorbereitung von Projekten zu vereinfachen.

## Umsetzung

Das Tool analysiert eine vorhandene Verzeichnisstruktur und erzeugt daraus die für den weiteren Avid-Workflow benötigten Strukturen.
