# Avid Project Creator

Der Avid Project Creator ist ein Python-Tool zur automatisierten Erstellung von Avid-Media-Composer-Projekten anhand vorhandener Verzeichnisse.

## Hintergrund

Bei regelmäßig wiederkehrenden Produktionen müssen neue Avid-Projekte mit einer einheitlichen Struktur angelegt werden. Da diese Arbeit rein repetetiv ist und in Avid Media Composer einige Zeit in Anspruch nimmt, konnte ich meinen Kolleg:innen einige Artbeit ersparen.

## Umsetzung

Das Python-Skript verarbeitet vorhandene Verzeichnisse und erstellt daraus die benötigten Avid-Projektstrukturen.
Neben einer Skriptversion enthält das Projekt auch eine Variante mit grafischer Benutzeroberfläche.
